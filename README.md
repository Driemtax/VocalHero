# VocalHero – Vocal Trainer for Beginners

VocalHero is a Java-based vocal trainer designed specifically for beginners. In various levels, users can practice singing single notes, intervals, and entire melodies by ear, improving their musical skills.

## Target Audience

- **Musicians and music enthusiasts**, especially beginners who want to improve their singing and pitch recognition.

## Features

- **Audio recording and playback:** Sing and listen back to your own recordings.
- **Note and melody playback:** Notes are generated programmatically, and melodies are stored as MIDI files.
- **Note recognition with FFT:** Automatic detection of sung notes using Fast Fourier Transform.
- **Vocal technique tips:** Practical advice during training sessions.
- **Microphone and speaker settings:** Customize your audio hardware setup.
- **Multilingual support:** Available in German and English.

## Technologies and Requirements

- **Programming language:** Java (minimum version 12)
- **GUI:** Swing (no additional libraries required; fully self-developed)
- **Tools:** No additional tools or dependencies needed

## Installation and Usage

1. **Clone the repository:**

git clone https://github.com/YOUR_USERNAME/VocalHero.git

2. **Compile and run:**
- **In VS Code:** Open the project and run it using the integrated development environment.
- **As an executable JAR:** The executable JAR file (`VocalHero.jar`) must be created by the user (see [project organization](#) for details).
3. **Start the application:**

java -jar VocalHero.jar
